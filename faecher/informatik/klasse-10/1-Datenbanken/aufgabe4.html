Klassenkarte und Tabellenschema

Übertrage dieselben Informationen zwischen dem objektorientierten und dem relationalen Modell.

Schritt 1 von 60 % bearbeitet
1

Einstieg

Zwei Ansichten derselben Information

Eine Klassenkarte zeigt eine Klasse mit ihren Attributen. Ein Tabellenschema zeigt dieselbe Struktur als Tabelle mit Spalten.

Für jede Spalte wird zusätzlich festgelegt, welche Art von Wert sie speichern darf.

Datentypen kurz wiederholt

varchar(255)
Text mit höchstens 255 Zeichen, z. B. ein Benutzername.
int
Ganze Zahl, z. B. eine ID.
char
Text mit fester Länge, z. B. ein zweistelliger Ländercode wie DE.
date
Ein Datum, z. B. ein Geburtstag.

Datentypen zuordnen

Wähle für jede Eigenschaft den passenden Datentyp.

2

Beispiel

So wird umgewandelt

Das Beispiel ist bewusst einfacher als die nächsten Aufgaben: Eine Bibliothek verwaltet Bücher.

Buch

  • titel
  • erscheinungsjahr
→umwandeln

buch

titel
varchar(255)
erscheinungsjahr
int

Merke die drei Schritte:

  1. Klassenname wird Tabellenname.
  2. Attribute werden Spalten.
  3. Jede Spalte erhält einen passenden Datentyp.

Beispiel verstehen

Wähle die zutreffende Aussage.

3

Anwenden

Klassenkarte users

Erstelle aus dieser Klassenkarte ein Tabellenschema. Die Reihenfolge der Zeilen ist egal.

users

  • id
  • username
  • birthday
  • created_at
  • updated_at

Dein Tabellenschema

Hilfe 1

Vergleiche jeden Attributwert mit den Beispielen aus der Datentyp-Wiederholung.

Hilfe 2

id ist eine ganze Zahl; ein Geburtstag ist ein Datum.

Hilfe 3

Für Namen und Zeitangaben brauchst du noch Text bzw. Datum. Prüfe außerdem, ob der Tabellenname der Klassenname ist.

4

Anwenden

Klassenkarte photos

Erstelle nun ein Tabellenschema für Fotos. Auch hier ist die Reihenfolge der Zeilen egal.

photos

  • id
  • description
  • url
  • created_at
  • updated_at

Dein Tabellenschema

Hilfe 1

Eine Beschreibung und eine URL bestehen aus Text; die ID ist eine Zahl.

Hilfe 2

Die beiden Attribute mit _at enthalten Datumsangaben.

Hilfe 3

Übertrage alle fünf Attribute. Prüfe danach, ob jedes genau einmal vorkommt.

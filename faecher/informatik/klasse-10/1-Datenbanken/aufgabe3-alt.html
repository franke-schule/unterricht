Fachbegriff

Der Fremdschlüssel (Foreign Key)

Die Spalte user_id in photos ist kein normales Attribut – sie ist ein Fremdschlüssel (englisch: Foreign Key).

Sie speichert nicht direkt einen Benutzernamen oder eine E-Mail, sondern die ID eines Datensatzes aus einer anderen Tabelle.

users Primärschlüssel-Tabelle

id PK username city
3 lukasmayer Hamburg
← verweist auf

photos Fremdschlüssel-Tabelle

id PK user_id FK description
4 3 Wanderung im Schwarzwald
Fremdschlüssel

Eine Spalte, die auf den Primärschlüssel einer anderen Tabelle verweist und so eine Verbindung zwischen zwei Tabellen herstellt.

💡
Exkurs: Referentielle Integrität

In professionellen Datenbanken sorgt die referentielle Integrität dafür, dass in photos.user_id nur IDs eingetragen werden dürfen, die auch wirklich als users.id existieren. Ein Foto ohne existierenden Benutzer kann so gar nicht erst entstehen!

Modellierung

Das Klassendiagramm

In der Informatik stellen wir solche Beziehungen in einem Klassendiagramm dar.

Die Boxen stellen die Tabellen/Klassen dar. Die Verbindungslinie zeigt die Beziehung mit ihren Multiplizitäten an den Enden.

users
  • id PK
  • username
  • email
  • city
photos
  • id PK
  • user_id
  • description
  • url

Lückentext im Klassendiagramm

Trage die 3 fehlenden Werte direkt in das Diagramm oben ein:

  • Auf der users-Seite des Pfeils: Multiplizität 1
  • Auf der photos-Seite des Pfeils: Multiplizität n
  • Neben user_id als Kürzel für Fremdschlüssel: FK

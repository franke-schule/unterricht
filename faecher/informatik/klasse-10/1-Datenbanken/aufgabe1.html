3

Verstehen

SQL-Datentypen

Wie in Java (int, String) legt auch SQL für jede Spalte fest, welche Art von Werten sie aufnimmt. Die Namen sind nur etwas anders.

Die vier SQL-Datentypen

INTEGER
Ganze Zahlen, zum Beispiel Alter oder IDs. Entspricht int.
VARCHAR(n)
Text mit variabler Länge, höchstens n Zeichen, zum Beispiel ein Vorname. Entspricht String.
CHAR(n)
Text mit fester Länge n. Kürzerer Text wird mit Leerzeichen aufgefüllt.
DATE
Ein Datum im Format YYYY-MM-DD.

Datentypen zuordnen

Ordne jedem Beispielwert den passenden SQL-Datentyp zu. Schreibe nur den Namen des Datentyps.

Hilfe 1

Frage dich zuerst: Ist der Wert Text oder eine Zahl?

Hilfe 2

Zwei der vier Werte sind Text. Unterscheide sie danach, ob ihre Länge fest ist oder wechseln kann.

Hilfe 3

„Anna-Maria“ ist variabler Text, 42 eine ganze Zahl, „w“ genau ein Zeichen, '2008-05-12' ein Datum.

Anwenden

Der Primärschlüssel

Zwei Personen heißen „Leon Müller“ und haben am selben Tag Geburtstag. Woran erkennt die Datenbank, wer von beiden gemeint ist?

Die zwei Regeln des Primärschlüssels

  • UNIQUE: Der Wert kommt in der Spalte nur ein einziges Mal vor.
  • NOT NULL: Das Feld darf nie leer bleiben.

Deshalb nimmt man dafür oft eigens vergebene Nummern wie eine Schüler-ID oder eine Kundennummer.

Finde den Schlüssel

Welches Attribut eignet sich am besten als Primärschlüssel der Tabelle Personen? Wähle genau eine Antwort aus.

Hilfe 1

Prüfe jede Möglichkeit mit den beiden Regeln UNIQUE und NOT NULL.

Hilfe 2

Ein Primärschlüssel darf sich nicht ändern und darf nie fehlen.

Hilfe 3

Namen wiederholen sich, E-Mail-Adressen können wechseln oder fehlen – eine eigens vergebene Nummer nicht.

Ein CREATE-TABLE-Schema lesen

Mit CREATE TABLE legt SQL das Gerüst einer Tabelle an: Name, Spalten, Datentypen und Primärschlüssel.

CREATE TABLE Videospiel (
  Spiel_ID INTEGER PRIMARY KEY,
  Titel VARCHAR(100),
  Erscheinungsjahr INTEGER,
  Preis_in_Cent INTEGER
);

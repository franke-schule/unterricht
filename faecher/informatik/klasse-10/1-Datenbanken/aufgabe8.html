4.1 Ergänze die Kardinalitäten bei »kann liken«, »kann kommentieren« und »kann folgen«.

Hilfe 1

Lies jede Beziehung in beide Richtungen, z. B.: Wie viele Fotos kann ein Benutzer liken? Von wie vielen Benutzern kann ein Foto geliked werden?

Die Beziehungstabelle (Hilfstabelle) follows

Auch Follower speichert InstaHub in einer Beziehungstabelle (Hilfstabelle). follower_id: wer folgt · following_id: wem gefolgt wird.

follows(
  id: int
  following_id[users]: int
  follower_id[users]: int
  created_at: date
  updated_at: date
)

follower_id: wer folgt · following_id: wem gefolgt wird

6.1 Entscheide: Was bedeutet die Zeile mit id 947?

6.2 zornigerfotograf und reisejoule folgen sich gegenseitig. Kreuze an, was stimmt.

Hilfe 1

Beachte die Erklärung über der Tabelle: follower_id ist der, der folgt. following_id ist der, dem gefolgt wird.

Hilfe 2

Übersetze jede id mithilfe von users in einen Benutzernamen und lies die Zeile dann als Satz: »follower folgt following«.

Hilfe 3

Zeile 1 heißt: reisejoule folgt zornigerfotograf. Vergleiche damit Zeile 2.

Richtig: follows ist die Beziehungstabelle (Hilfstabelle) zu users n ───── m users. Beide Fremdschlüssel verweisen auf users, und jede Zeile beschreibt eine Richtung. In InstaHub sind likes, comments und follows solche Beziehungstabellen (Hilfstabellen).
Merksatz

Eine n:m-Beziehung wird durch eine Beziehungstabelle umgesetzt. Jede Zeile verbindet über zwei Fremdschlüssel genau einen Datensatz der einen Tabelle mit genau einem Datensatz der anderen Tabelle.

Eine Beziehungstabelle heißt auch Hilfstabelle.

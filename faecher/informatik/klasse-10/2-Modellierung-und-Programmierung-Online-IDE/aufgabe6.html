Infokarte: Die erweiterte Klassenkarte

Eine erweiterte Klassenkarte zeigt nicht nur Namen, sondern auch Datentypen. Beispiel: ein Ausschnitt der Klasse Ball aus Aufgabe 1.

Ball

  • geschwindigkeit: int
  • ball: Circle
  • Ball(startX: float)
  • act(): void
  • setzeBallfarbe(neueFarbe: String): void

Attribute mit Datentyp

name: Datentyp, z. B. geschwindigkeit: int (ganze Zahl) oder ball: Circle – hier ist eine Klasse der Datentyp.

Eingabeparameter

Sie stehen mit Datentyp in den runden Klammern, z. B. setzeBallfarbe(neueFarbe: String). Eine Methode ohne Eingabeparameter hat leere Klammern: act().

Ausgabeparameter (Rückgabetyp)

Er steht nach einem Doppelpunkt hinter der Klammer. void heißt: Die Methode gibt keinen Wert zurück. Liefert eine Methode eine ganze Zahl, steht dort int, z. B. gibGeschwindigkeit(): int.

Konstruktor

Er trägt den Namen der Klasse, steht im Methodenbereich und hat keinen Rückgabetyp, z. B. Ball(startX: float).

Aus void setzeBallfarbe(String neueFarbe) im Code wird in der Klassenkarte setzeBallfarbe(neueFarbe: String): void.

Merkkarte: Vererbung und Polymorphie

Oberklasse und Unterklasse

Computer ist eine Unterklasse von Artikel, Laptop eine Unterklasse von Computer. Es gilt die „ist ein“-Beziehung: Ein Laptop ist ein Computer, und ein Computer ist ein Artikel.

extends

class Computer extends Artikel bedeutet: Computer erbt alle Attribute und Methoden von Artikel. Deshalb hat ein Computer-Objekt auch name, preis und gewicht, ohne dass sie in Computer noch einmal stehen.

super(…)

Im Konstruktor der Unterklasse ruft super(_name, _preis, _gewicht); den Konstruktor der Oberklasse auf. So bekommen die geerbten Attribute ihre Werte.

Überschreiben

Eine Unterklasse kann eine geerbte Methode neu definieren: gleicher Name, gleiche Parameter, eigener Inhalt. @Override kennzeichnet das. Überschreibt eine Unterklasse eine Methode nicht, wird die geerbte Methode ausgeführt.

Polymorphie

Eine Variable vom Typ der Oberklasse kann auf ein Objekt einer Unterklasse verweisen: Artikel smart1 = new Smartphone(…);. Beim Aufruf smart1.zeigeInfos(); wird die Methode des tatsächlichen Objekts ausgeführt, hier also zeigeInfos() aus Smartphone. Derselbe Aufruf führt so je nach Objekt zu unterschiedlichem Verhalten.

Im Klassendiagramm

Ein Pfeil mit leerer Dreiecksspitze zeigt von der Unterklasse zur Oberklasse. Geerbte Attribute stehen nur in der Oberklasse. Eine überschriebene Methode steht in der Karte der Unterklasse noch einmal.

  • fahren(): void

Fahrrad

Übersicht: alle Teilaufgaben und Ergebnisse

Hier stehen alle Arbeitsaufträge dieser Aufgabe mit ihren Ergebnissen – gut geeignet für die gemeinsame Besprechung.

a) Klassen programmieren

Wandle das Klassendiagramm in Java-Code um. Lege für Hund, Katze und Delfin je eine eigene Datei an; Tätigkeiten wie bellen() geben nur einen Text mit println aus.

Richtiges Ergebnis
Hund, Katze und Delfin erben mit extends Tier die Attribute name und alter sowie zeigeDaten(). Jede Unterklasse deklariert nur ihr eigenes Attribut und ihre eigene Methode; Hund und Katze überschreiben zeigeDaten(). 
class Tier {
   int alter;
   String name;

   void zeigeDaten() {
      println("Das Tier " + name + " ist " + alter + " Jahre alt.");
   }
}

class Hund extends Tier {
   String rasse;

   void bellen() {
      println(name + " bellt: Wuff!");
   }

   @Override
   void zeigeDaten() {
      println("Der Hund " + name + " ist " + alter + " Jahre alt. Rasse: " + rasse);
   }
}

b) Eigenes Testprogramm

Erzeuge in Hauptprogramm.java Objekte von Tier, Hund, Katze und Delfin, gib ihnen Werte und rufe ihre Methoden auf. Baue mindestens einen polymorphen Aufruf ein: eine Variable vom Typ Tier, die auf einen Hund oder eine Katze verweist. Vergleiche die Ausgabe von zeigeDaten() bei Hund und Delfin.

Richtiges Ergebnis
Ein Testprogramm erzeugt Objekte aller vier Klassen, weist Werte mit der Punktnotation zu und ruft ihre Methoden auf. Polymorph: Tier t = new Katze(); t.zeigeDaten(); führt zeigeDaten() aus Katze aus.

Richtiges Ergebnis
Delfin nutzt die geerbte zeigeDaten() aus Tier, Hund und Katze nutzen ihre eigene.

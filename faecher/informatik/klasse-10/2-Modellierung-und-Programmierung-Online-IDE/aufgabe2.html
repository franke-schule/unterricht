Definiert Attribute und Methoden

Auto.java 
public class Auto {
    // Attribute
    String marke;
    String farbe;
    int geschwindigkeit;

    // Konstruktor
    Auto(String m, String f) {
        marke = m;
        farbe = f;
        geschwindigkeit = 0;
    }

    // Methoden
    void beschleunige(int wert) {
        geschwindigkeit += wert;
    }

    void bremse() {
        geschwindigkeit = 0;
    }
}

💡 Der Unterschied

Klasse = Bauplan

  • Existiert nur einmal im Code
  • Definiert, WELCHE Eigenschaften Objekte haben
  • Definiert, WAS Objekte tun können
  • Hat selbst keine konkreten Werte

Objekt = Instanz

  • Es können beliebig viele erstellt werden
  • Jedes hat EIGENE Attributwerte
  • Wird mit new erzeugt
  • Belegt Speicherplatz im Heap
